1

구글폼 만들기 ⏱️ 1분

forms.google.com에서 새 폼 생성

필수 질문 5개 추가:

  • ✅ 이름 (단답형, 필수)
  • ✅ GitHub 아이디 (단답형, 필수)
  • ⭕ GitHub Pages URL (단답형, 선택)
  • ✅ 그룹/강좌명 (객관식, 필수)
  • ⭕ 썸네일 이미지 URL (단답형, 선택)
✅ 팁: "응답" 탭에서 "스프레드시트 만들기"를 클릭하면 자동으로 연결됩니다!
2

스프레드시트 설정 ⏱️ 1분

생성된 스프레드시트에서:

⚠️ 중요! 시트 이름을 "학생정보"로 변경하세요!
(하단 탭 더블클릭 → "학생정보" 입력 → Enter)
3

Apps Script 설정 ⏱️ 2분

확장 프로그램 → Apps Script 메뉴 클릭

제공된 google-apps-script.js 코드를 전체 복사하여 붙여넣기

function doGet(e) { const sheet = SpreadsheetApp .getActiveSpreadsheet() .getSheetByName('학생정보'); // ... 나머지 코드 }
💾 저장 후 프로젝트 이름: "학생 갤러리 API"
4

웹 앱 배포 ⏱️ 1분

배포 → 새 배포 클릭

설정:

  • 유형: 웹 앱
  • 실행 계정: 나
  • 액세스 권한: 전체 사용자 (익명 포함)
⚠️ "안전하지 않음" 경고가 나오면:
고급 → [프로젝트명](으)로 이동 → 허용
(본인이 만든 스크립트이므로 안전합니다)
🎉 웹 앱 URL이 생성됩니다! 이 URL을 복사해두세요.
https://script.google.com/macros/s/AKfycby.../exec

웹사이트 설정 ⏱️ 30초

GitHub Pages 배포 ⏱️ 30초

GitHub 저장소에 업로드:

git clone https://github.com/your-username/repo.git cd repo cp student-gallery-google-sheets.html index.html git add index.html git commit -m "학생 갤러리 추가" git push
🌐 Settings → Pages에서 배포 활성화
몇 분 후 https://your-username.github.io/repo/에서 확인!
